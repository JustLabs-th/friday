# Liam: รายการทดสอบบนเครื่องสะอาด และคู่มือผู้ทดสอบ (pilot)

เอกสารนี้มี 2 ส่วน: (ก) รายการตรวจสำหรับคนติดตั้งและทดสอบบนเครื่องที่ยังไม่เคยลง Liam (ข) ข้อความสำหรับส่งให้ผู้ทดสอบ

## ก. รายการตรวจ (ทำทีละข้อ ติ๊กผ่าน/ไม่ผ่าน และจดสิ่งที่เห็น)

เตรียม: เครื่อง Windows 10/11 ที่อยู่ในเครือข่ายบริษัท ไม่เคยลง Liam ใช้บัญชีบริษัทของผู้ทดสอบ รู้สิทธิ์ admin (ตัวติดตั้งขอสิทธิ์ครั้งเดียว)

### 1. ติดตั้ง
- [ ] ดับเบิลคลิกตัวติดตั้ง `Liam_*_x64-setup.exe` ขึ้นหน้าขอสิทธิ์ผู้ดูแล (UAC) ติดตั้งจบโดยไม่ error
- [ ] ไม่มี Windows SmartScreen / Cylance บล็อก (ถ้ามี จดข้อความและชื่อไฟล์ที่ถูกบล็อก)
- [ ] ไฟล์ `C:\Program Files\Liam\installer\network-setup.log` มีบรรทัด `hosts updated` และ `names under digitalx.srt are asked of 192.168.100.9` (ไม่มี `FAILED`)
- [ ] `nslookup nexus.digitalx.srt` ได้ `192.168.100.24`
- [ ] `nslookup anything.apps.digitalx.srt` ได้ `192.168.100.15` (นี่คือกฎ DNS ที่เพิ่ม ถ้าไม่ได้ จดผลทั้งหมด)

### 2. เปิดโปรแกรมและเข้าสู่ระบบ
- [ ] เปิด Liam ได้ หน้าต่างไม่ว่าง
- [ ] กดเข้าสู่ระบบ → เบราว์เซอร์เปิดหน้า SSO **ไม่ขึ้น "Not secure"** → ล็อกอินแล้วกลับมาที่ Liam
- [ ] ชื่อของตัวเองขึ้นในโปรแกรม

### 3. สร้างและ deploy แอป
- [ ] สร้างแชตใหม่ สั่ง "ทำเว็บบันทึกงานง่ายๆ ชื่อระบบบันทึกงาน" agent ตอบเป็นภาษาไทยและทำจนจบในรอบเดียว
- [ ] แถบสถานะด้านบนข้อความขึ้นระหว่างทำงาน (ชื่องาน เวลา โทเค็น) และมีบรรทัดสรุปตอนจบ
- [ ] แผงขวา: Context ขึ้นตัวเลข, Outputs มีรายชื่อไฟล์
- [ ] สั่ง "deploy ให้หน่อย" ได้ที่อยู่ `http://<ชื่อ>.apps.digitalx.srt` และขึ้นในบอร์ด Homarr
- [ ] เปิดที่อยู่นั้นในเบราว์เซอร์ **จากเครื่องนี้** → เด้งไปล็อกอิน SSO → กลับมาเห็นแอป ไม่ใช่หน้า error ของ proxy (Squid)
- [ ] มุมขวาบนของแอปมีชื่อผู้ใช้ เมนูโปรไฟล์ เปิดเมนูได้ มีตัวเลือกธีมและออกจากระบบ
- [ ] กดออกจากระบบ → ล็อกอินใหม่ → กลับมาที่หน้าแอปเดิม

### 4. แอปรู้ว่าใครใช้
- [ ] สั่ง "แสดงชื่อและรหัสพนักงานของผู้ใช้ในหน้าแรก แล้ว deploy ใหม่" หน้าแอปแสดงชื่อและรหัสพนักงานที่ถูกต้อง (ไม่ใช่ `Dev User`)

### 5. ถอนการติดตั้ง
- [ ] ถอนการติดตั้งได้ บรรทัดของ Liam ใน `hosts` หายไป และ `nslookup anything.apps.digitalx.srt` กลับไปเป็นผลเดิมของเครื่อง

### ถ้าไม่ผ่าน เก็บข้อมูลเหล่านี้
- ไฟล์ `network-setup.log` (ข้างต้น)
- ภาพหน้าจอตรงที่ติด และข้อความ error เต็ม
- ผล `ipconfig /all` และ `nslookup nexus.digitalx.srt`
- ข้อความของ agent ที่หยุดกลางงาน (วางทั้งบทสนทนา)

## ข. ข้อความส่งให้ผู้ทดสอบ

> **ทดสอบ Liam (รอบ pilot)**
>
> Liam คือโปรแกรมที่คุณสั่งเป็นภาษาไทยให้สร้างเว็บแอปภายในบริษัท แล้ว deploy ให้เปิดใช้ได้ทันที ล็อกอินด้วยบัญชีบริษัท
>
> **วิธีทดสอบ**
> 1. ติดตั้งตามไฟล์ที่ได้รับ (ขอสิทธิ์ผู้ดูแลครั้งเดียว) แล้วเปิดโปรแกรมและเข้าสู่ระบบ
> 2. ลองสั่งให้ทำเว็บเล็กๆ ที่คุณใช้จริง เช่น ฟอร์มบันทึกงาน ตารางสรุป
> 3. สั่ง "deploy" แล้วเปิดที่อยู่ที่ได้
> 4. บอกเราว่าอะไรใช้ได้ อะไรทำให้งง อะไรพัง
>
> **ควรรู้ก่อนใช้**
> - ตอนนี้ใช้ **http** (ยังไม่เข้ารหัส) อย่าใส่ข้อมูลลับหรือข้อมูลบุคคลจริงจำนวนมาก
> - แอปยังไม่มีฐานข้อมูลกลาง ข้อมูลที่กรอกจะไม่ถูกเก็บถาวรและไม่แชร์ระหว่างคน
> - ทุกคนที่มีบัญชีบริษัทเปิดแอปของคุณได้ (ยังไม่มีการจำกัดสิทธิ์ต่อแอป)
> - บางครั้ง agent อาจหยุดกลางงาน พิมพ์ว่า "ทำต่อ" ได้
> - ใช้งานในเครือข่ายบริษัทเท่านั้น
>
> **ส่งผลให้ใคร:** <ชื่อผู้ดูแล pilot> พร้อมภาพหน้าจอและข้อความ error ถ้ามี
